# 🛡️ Smart Surveillance System

### AI-Powered Security Analytics and Threat Detection

A web-based Smart Surveillance System designed to support security monitoring and threat detection using modern web technologies and AI-based computer vision.

🌐 **Live Demo:** [Open Smart Surveillance System](https://lucky-brioche-ac6782.netlify.app)

---

## 📌 About the Project

The **Smart Surveillance System** aims to make security monitoring smarter by combining a web interface with AI-powered surveillance concepts. The project is designed to help users explore intelligent monitoring, visual analysis, and threat detection through a modern web application.

## ✨ Features

- 🖥️ **Modern Web Interface** — Simple and user-friendly design.
- 🔍 **Security Monitoring** — Interface for surveillance-related activities.
- 🤖 **AI-Based Detection Concept** — Designed with AI-powered threat detection in mind.
- 🎯 **YOLO Integration Concept** — Supports the planned use of YOLO for object detection.
- 👁️ **Computer Vision** — Designed to work with OpenCV-based image or video analysis.
- 🌐 **Live Web Deployment** — Accessible online through Netlify.
- 📱 **Responsive Design** — Intended to support different screen sizes.

> Note: Actual detection features depend on the implemented code and any required backend services. Features described as planned or conceptual may require further development.

## 💻 Run the Project Locally

### Prerequisites

- Node.js (LTS version)
- npm
- Git (optional, for cloning)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gouthamsathishkumar-pixel/-Smart-Surveillance-System-.git
   ```

2. Open the project folder:

   ```bash
   cd -Smart-Surveillance-System-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the localhost URL displayed in your terminal.

### Build for Production

```bash
npm run build
```

The production-ready website files will be generated in the `dist` directory.
